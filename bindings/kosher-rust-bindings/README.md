# kosher-ffi

Experimental: a C ABI for kosher-rust, with bindings for other languages generated by
[WeaveFFI](https://weaveffi.com).

`src/lib.rs` is a small FFI-shaped facade over kosher-rust: times are Unix milliseconds, time
zones are IANA names, and a zman is named by its KosherJava getter (`"getSofZmanShmaGRA"`).

```bash
cargo install weaveffi-cli --version 0.25.0 --locked
cd bindings/kosher-ffi
weaveffi generate          # builds the crate, writes generated/<language>/
```

Try it from Python (Windows path shown; use `libkosher_ffi.so` / `.dylib` elsewhere):

```bash
KOSHER_FFI_LIBRARY=../../target/debug/kosher_ffi.dll PYTHONPATH=generated/python python examples/smoke.py
```
